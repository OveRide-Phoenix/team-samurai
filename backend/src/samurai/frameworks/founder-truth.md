# Founder truth

Use this reference to make the current decision legible without turning conviction into evidence.

Classify each material statement:

- **Known:** directly observed behavior, payment, usage, customer words, shipped facts, or a traceable source.
- **Believed:** a reasonable interpretation that still needs a test or stronger source.
- **Hoped:** an aspiration or optimistic outcome with no supporting signal yet.

Name one current bottleneck: the uncertainty that blocks the next useful unit of work. Record the strongest contradiction or evidence gap around it. Choose one next founder decision and the smallest action that could change that decision.

Preserve corrections and prior context unless the founder changes them. Ask only for missing information that changes the next decision. New evidence may move a statement between categories; fluent wording or agreement from another agent may not.

This framework organizes a draft. It does not establish demand, feasibility, revenue, or customer validation.
